# Frog Escape 검증 보고서

검증일: 2026-10-28. Unity 6000.3.23f1, Windows, URP.

최신 단계: 주행 연출과 천장으로 둘러싸인 하수도를 추가한 버전도 Easy/Normal 각각 34/34 PASS. 상세 결과·수동 화면 점검·입력 설정 복원은 `FeelAndSewer.md`를 참고한다. 아래 초기 구현의 빌드 크기와 성능 수치는 당시 실행 기록이며 최신값은 JSON에 기록된다.

추가 UI·그래픽 개선 후 Easy/Normal 전체 검사도 각각 34/34 PASS. 최신 JSON은 새 아트 버전의 결과이며 아래 최초 구현 수치는 이전 실행 기록이다. 최신 변경과 화면 점검은 `VisualUpgrade.md`, 최신 빌드 수치는 `BuildResult.json`을 참고한다.

## 검증 방법

실행 중인 Unity Editor에 연결하여 컴파일, Play Mode 및 실제 Input System 키 입력을 검사했다. `Tests/PlaytestDriver.cs`는 에디터에서만 컴파일되며 배포 빌드에는 포함되지 않는다. 기본 조작은 실제 시간, 전체 경로는 3배 시간으로 실행한다. 시간 배율은 씬 전환 후에도 테스트 드라이버가 유지한다.

각 난이도 JSON의 `status`, `checks`, `failures`가 최종 기계 판정 원본이다. 테스트는 체력/재시작 검증을 위해 고의 피격을 주입하고 수로에서 체력을 복구한다. 따라서 해당 기록을 일반 참가자의 무보조 완주 기록으로 해석하지 않는다.

## 확인 범위

최종 Play Mode 결과: **Easy 34/34 PASS, Normal 34/34 PASS**, 실패 목록 모두 비어 있음. Easy 게임 시간 193.42초, Normal 191.27초(컷신 제외, 검사 중 재시작 전 플레이 포함). 실제 검사 소요 시간은 각각 84.72초/84.02초이다. 조작 검사 구간 평균 에디터 FPS는 55.55/55.48로, 60 FPS 목표 달성은 아직 확인하지 못했다. 전체 경로는 3배 시간 검사이므로 이 값을 실제 플레이 프레임 성능으로 일반화하지 않는다.

별도 실행 중 상태 검사: 고가도로 26개 행 모두 안전 차선 존재, 이동 장애물의 원점 대비 이동 거리 12 이하.

- 자동 전진, A/D·방향키 이동, 도로 경계 제한.
- ESC 일시정지와 위치 유지, 재개, Space 회피 및 재입력 쿨다운.
- 같은 프레임 중복 피해 방지, 실패 화면, 현재 스테이지 재시작과 체력 복구.
- 고가도로 → 벽타기 Timeline → 수로 → 탈출 Timeline → 유도탄 → 엔딩 Timeline → CLEAR → 타이틀.
- 탄환 교차 피격, 풀 재사용 시 상태 초기화, 피격 무적.
- 유도탄 조기 회피 실패와 초록 신호 회피, 마지막 성공 후 엔딩 연결.
- 메뉴, 고가도로, 수로, 유도탄, 컷신, 결과 화면의 캡처 검토.

## 최종 수정

움직이는 장애물은 원래 행에서 전방 12 이내로 이동하도록 제한했다. 기본 행 간격 62에서 최소 간격 50을 남겨 다른 행과 합쳐져 모든 통로를 막는 현상을 방지한다. 경찰은 전방 60 안의 가장 가까운 장애물 행을 먼저 고려한다. 경찰 경광등 크기 누적, 수로 카메라 높이, 하단 조작 안내 줄바꿈, 쉬움 마지막 공격 체력 보완의 반복 적용도 수정했다.

## 원본 보존

작업 전 `Backups/BeforeFrogEscape.zip`을 생성했다. 기존 파일 변경은 게임 씬을 등록한 `ProjectSettings/EditorBuildSettings.asset`에 한정하는 것을 목표로 하며, 최종 해시 비교는 `OriginalFilesChanged.txt`에 기록한다. 기존 SampleScene은 유지한다. 새 게임 자산은 `Assets/FrogEscape`, 공식 TMP 리소스는 `Assets/TextMesh Pro`에 있다.

## Windows 빌드

`Builds/FrogEscape/FrogEscape.exe`, Windows x64, 비개발 배포 빌드 성공. 최종 BuildResult.json: 오류 0, 경고 0, 115,835,811 bytes. 첫 빌드의 TMP 구식 줄바꿈 API 경고는 동일 기능의 `textWrappingMode=TextWrappingModes.Normal`로 교체하여 해결했다. 게임 로직 검사는 교체 직전 버전에서 실행했고, 교체 후 컴파일과 배포 빌드를 다시 확인했다.

독립 실행 파일을 Computer Use로 열려고 했으나 `Computer Use app approval timed out`으로 중단되었다. 따라서 독립 실행 파일의 시작 화면·조작·전체 완주는 **미검증**이다. 위 전체 경로 PASS는 Unity Editor Play Mode 결과다. 행사 배포 전 exe를 실행하여 한국어 표시, 오디오, 전체 진행과 실제 프레임 성능을 확인해야 한다.

## 남은 현장 검증

프리미티브 기반 로우폴리 초기 버전이다. 실제 초등학생의 조작 이해 시간·완료율은 미측정이다. 자동 검사는 체험 난이도나 연출의 재미를 증명하지 않는다. 에디터 FPS는 테스트 도중의 참고값이며 행사 PC의 1920×1080 60 FPS 보장으로 해석하지 않는다. 한국어는 Windows에 설치된 맑은 고딕을 사용하므로 행사 PC에서 글꼴과 음량을 확인해야 한다.
