# 아케이드 스타일 UI·그래픽 개선

2026-10-28. 로블록스 아케이드 게임에서 흔히 볼 수 있는 밝은 색상, 큰 버튼, 둥근 패널, 굵은 글씨와 그림자 중심으로 기존 Unity 게임을 개선했다. Roblox 자산이나 로고를 가져온 것은 아니다.

## 변경 내용

- 타이틀·일시정지·실패·성공 메뉴: 라운드 패널, 입체적인 초록/파랑/주황 버튼, 새로운 타이틀과 배지.
- HUD: 하트 체력, 두꺼운 초록 진행 막대, 굵은 단계 표시, 회피 안내, 읽기 쉬운 배경이 있는 피드백.
- 바이크: 엔진 냉각핀, 배기구, 프런트 포크, 사이드미러, 휠 장식, 레이싱 줄무늬. 캐릭터: 배낭과 어깨끈.
- 경찰차: 범퍼, 그릴, 배지, 미러, 휠 허브, 안테나. 일반 차량: 바퀴·후미등·범퍼. 공사 장애물: 받침·경고등.
- 도시: 다채로운 건물, 창문, 옥상 테두리와 장치, 구름, 수목, 도로 연석·반사판·표지판.
- 수로: 배관과 연결부, 배수구, 서비스 패널, 방향 표지판.
- 야외: 초록 언덕, 나무와 관목, 구름, 밝은 하늘과 조명.

## 구현 및 보존

`GameHUD.cs`의 기존 메뉴 콜백과 입력 방식을 유지했다. 새 모서리 스프라이트는 실행 시 한 번 생성하고 씬 간 공유한다. 배경 추가물은 `Arcade Detail Pass` 아래에 보관하며, 재적용 시 중복 생성하지 않는다. 장식에는 충돌체가 없다. 정적 장식 메시를 재질별·120 거리 구간별로 합쳐 컬링을 유지하며 드로 콜 증가를 줄였다.

`ArcadeVisualUpgrade.Apply()` 또는 Unity 메뉴 `Frog Escape > Apply Arcade Visual Upgrade`로 적용한다. 변경 전 게임 에셋은 `Backups/BeforeArcadeVisuals.zip`에 보관했다. 원래 SampleScene, 게임 시간, 난이도, 충돌 판정과 AI 데이터는 바꾸지 않았다.

## 검증

에디터에서 새 타이틀, 3개 스테이지와 컷신·결과 화면을 캡처했다. Canvas와 EventSystem은 각각 1개다. 하단 조작 안내는 한 줄이며 텍스트 영역 넘침이 없음을 실행 중 확인했다. 전체 진행 자동 검사의 최신 결과는 `Playtest-Easy.json`, `Playtest-Normal.json`, Windows 빌드 결과는 `BuildResult.json`에서 확인한다.

이번 변경 후 Easy 34/34, Normal 34/34 PASS. 마지막 카메라 높이 조정은 전체 검사 후 별도 Play Mode 화면으로 점검했다. 표지판 글자 방향을 수정했고, 지상 카메라 높이를 7에서 5.5로 내려 표지판 통과 시 전방 시야를 확보했다. 검증 캡처는 `Screenshots/Arcade-Title.png`, `Screenshots/Arcade-Gameplay.png` 및 `Normal-scene-*.png`에 있다.

모델과 배경은 스타일화된 프리미티브 기반이다. 행사 PC의 전체 화면 성능과 실제 어린이 사용성 검증은 별도로 필요하다. 이번 작업은 에디터 검증과 빌드까지이며 독립 실행 파일 전체 완주는 별도로 보증하지 않는다.
